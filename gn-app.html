← ප්‍රධාන පිටුවට (Home)

පද්ධතිය පිළිබඳ හැඳින්වීම

ග්‍රාම නිලධාරී වසමක පවුල් සහ පුද්ගල තොරතුරු ආරක්ෂිතව, විධිමත්ව හා කාර්යක්ෂමව පාලනය කිරීම සඳහා විශේෂයෙන් නිර්මාණය කරන ලද මෘදුකාංග පද්ධතියකි. මෙමඟින් දත්ත සෙවීම, වාර්තා සැකසීම සහ සහතික පත් ලබා දීම ඉතා ඉක්මනින් සිදු කළ හැක.


ප්‍රධාන විශේෂාංග (Key Features)

  • පවුල් සහ පුද්ගල තොරතුරු ඇතුළත් කිරීම සහ යාවත්කාලීන කිරීම.
  • ක්ෂණිකව දත්ත සෙවීමේ පහසුකම (Advanced Search by NIC / Name / House No).
  • ජ්‍යෙෂ්ඨ පුරවැසියන්, අස්වැසුම ප්‍රතිලාභීන් සහ විශේෂ අවශ්‍යතා සහිත අයගේ ලැයිස්තු වෙන්කර ගැනීම.
  • විවිධ නිල වාර්තා (Reports) පහසුවෙන් Print/Export කරගැනීමේ හැකියාව.
  • දත්ත ආරක්ෂිතව පවත්වා ගැනීමට පරිශීලක මුරපද (User Authentication).

භාවිත කළ තාක්ෂණයන් (Technologies Used)

MySQL Server Desktop UI Framework Database Management
